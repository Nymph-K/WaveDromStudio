WaveDrom Studio — 一键启动版 / One-click portable edition
==========================================================

【中文】
1. 解压整个文件夹。
2. 双击 START.cmd，或直接双击 WaveDromStudio.html。
3. 浏览器会打开应用。无需安装、无需联网、无后端。
4. 建议使用最新版 Chrome、Edge 或 Firefox。
5. 这是完全独立的单文件版；所有脚本、样式和图标都已内嵌。
6. WaveJSON 草稿保存在当前浏览器的 localStorage 中。
7. 如需跨设备或部署到服务器，请使用静态版 dist/ 或 GitHub Release 中的 static zip。

【English】
1. Extract the whole folder.
2. Double-click START.cmd, or open WaveDromStudio.html directly.
3. The app opens in your browser. No installation, network access or backend required.
4. A current Chrome, Edge or Firefox is recommended.
5. This is a fully self-contained single HTML file; scripts, styles and icons are embedded.
6. Drafts are stored in the current browser's localStorage.
7. For deployment on a server, use the static dist/ build or the static zip from the GitHub Release.

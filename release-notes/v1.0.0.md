# WaveDrom Studio v1.0.0

首个公开版本：可直接双击启动的 WaveJSON 可视化编辑器。

## 一键启动 / One-click

- `WaveDromStudio.html` — 单文件版，下载后直接用浏览器打开。
- `WaveDromStudio-one-click.zip` — 解压后双击 `START.cmd`（Windows），或直接打开 HTML。
- `wavedrom-studio-v1.0.0-static.zip` — 可部署到任意静态站点。

无需安装、无需联网，所有编辑都在浏览器内完成。

## 本版修复 / Fixes

1. 空白周期可视化框选可一直向右拖动，自动滚动并扩展画布。
2. `clk` / `clock` 信号自动伸展或缩短到最长非时钟信号；可在偏好设置中关闭。
3. 空 `data` 标签现在有可双击的占位符，`Tab` 也会跳入空标签。
4. `Ctrl+Enter` 新增信号后自动进入信号名内联编辑。
5. 修复多选信号后分组只包含一条信号的问题。
6. 新增左侧编辑工具栏：时钟、电平信号、总线、未知、高阻、间隔、文本、清除、节点。
7. 新增 English / 简体中文界面，可在页头或偏好设置切换，语言会持久化。
8. 插入模式（INS）会在所有选中行显示光标；支持鼠标中键拖动进入多行插入模式。
9. 关闭已修改的标签页时提示保存；关闭浏览器标签时会触发浏览器离开确认。
10. 新增单文件一键启动构建与 `pnpm start`。

## 功能 / Features

- 官方 WaveDrom SVG 渲染器，官方 light / dark 皮肤。
- JSON5 + 严格 JSON、错误行列提示、保留上一份有效波形。
- 画布绘制、矩形框选、内联信号名 / data 标签编辑、拖拽排序、嵌套分组。
- 时钟、总线、未知、高阻、间隔、文本、清除、节点编辑模式。
- 多标签独立源码 / 选区 / 缩放 / 滚动位置，统一撤销重做。
- 自适应时钟、时间标尺、亮色/暗色主题、SVG/PNG/JSON 导出。
- 本地自动草稿、URL 分享、系统剪贴板、快捷键自定义与冲突检测。
- 响应式单栏布局，纯静态，无后端。

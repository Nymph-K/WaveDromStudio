# WaveDrom Studio v1.0.1

Bugfix release for v1.0.0.

## 修复 / Fixes

- **分组组名自动编辑**：多选信号打包分组时，组名输入框现在会自动获得焦点并全选默认名称，打开后可直接输入。
- **新增信号位置**：`Ctrl+Enter` / “信号”按钮现在会在当前选中信号下方插入新信号，而不是放到所有信号末尾。
- **信号名内联编辑**：修复输入一个字符后文本框重新全选、导致后续输入覆盖前文的问题；输入内容会正常保留。
- **中文术语**：界面与文档中的 timing cycle 统一译为 **周期**（原“循环”）；时钟工具的“依次切换”提示也同步优化。

## 一键启动 / One-click

- `WaveDromStudio.html` — 单文件版，下载后直接用浏览器打开。
- `WaveDromStudio-one-click.zip` — 解压后双击 `START.cmd`（Windows），或直接打开 HTML。
- `wavedrom-studio-v1.0.1-static.zip` — 可部署到任意静态站点。

**在线演示 / Live demo:** https://nymph-k.github.io/WaveDromStudio/

## 验证 / Verification

- 38 项单元测试通过；TypeScript、Oxlint、静态构建和单文件构建通过。
- 浏览器验证：组名输入自动聚焦并全选、输入 `ABC` 正常替换默认名；内联信号名连续输入不再被覆盖；新信号插入到选中信号下方；中文周期文案显示正确。

完整项目说明见 [README.md](https://github.com/Nymph-K/WaveDromStudio#readme)。
